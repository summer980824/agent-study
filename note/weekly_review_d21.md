## 问题：为什么 AI 工程项目不能只关注模型调用，还需要日志、测试、超时和并发控制？
- 可靠性：外部模型 API 可能超时、限流或返回错误。错误控制机制优化流程。
- 可观测性：结构化日志帮助定位失败原因、追踪请求。
- 可测试性：Mock 外部服务可以稳定、低成本地验证业务逻辑。
- 资源控制：利用Semaphore并发限制有助于避免触发 API 限流并控制资源消耗。
- 可维护性：CLI、配置和模块化设计让项目更容易运行、测试和扩展。
