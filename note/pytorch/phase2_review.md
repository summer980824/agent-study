## 如何证明模型真正学到了规律，而不是记住了训练样本？

**答**：核心思路是——**记忆只能复述见过的数据，规律可以泛化到没见过的数据**。所以证明方法都是构造"模型没见过"的场景，检验它是否依然表现正确。单一指标不够，通常要以下几种证据互相印证。

### 1. 留出测试集 / 验证集（最基本的证据）

训练集和测试集必须**严格隔离**，模型训练时从未见过测试数据：

```python
train_loss = evaluate(model, train_loader)   # 见过
test_loss  = evaluate(model, test_loader)    # 没见过
```

- 如果 test_loss 和 train_loss 接近 → 学的是规律
- 如果 train_loss 很低而 test_loss 很高 → 记住了训练样本（过拟合）

关键坑：数据泄漏会让测试集失效——比如归一化统计量、tokenizer 词表、特征工程用了全量数据，或同一样本的近似重复同时出现在训练和测试里。

### 2. 观察训练曲线（动态证据）

画两条曲线：train_loss 和 val_loss 随 epoch 的变化。

- 正常：两条都下降，最终收敛且差距不大
- 过拟合信号：train_loss 持续下降，val_loss 先降后升——升上去的那个拐点之后，模型就在背训练集了

配合早停（early stopping）和 checkpoint 选 val_loss 最低的权重，是标准的防记忆手段。

### 3. 同分布新样本上的泛化（直接的证据）

构造训练集中不存在的输入，检验输出是否合理：

- 加法任务：训练 `a+b`，测试时给没见过的数字组合，看结果对不对
- 噪声测试：给输入加微小扰动（`x + ε`），规律模型输出应基本不变，记忆模型可能剧烈波动（这也是一种对抗鲁棒性检验）

### 4. 扰动不变性检验

规律应该对无关变化不敏感：

- 图像分类：平移、缩放、翻转后预测标签不变
- 文本：同义改写后预测不变

如果模型只对训练集里出现过的"精确样本"正确，一扰动就错，说明它记住的是样本本身。

### 5. 权重与激活的间接证据

- 决策边界可视化（2D  toy 任务）：规律模型的边界是平滑简单的曲线；记忆模型的边界会绕着训练点"打卷"
- 注意力/特征分析：看模型是否关注到了任务真正相关的特征（如注意力权重是否落在关键词上）

### 6. 理论判别：插值 vs 外推

可以区分两种"没见过"：

- **插值**（interpolation）：测试点在训练数据覆盖的范围内 → 过拟合的模型也能做对，证明力弱
- **外推**（extrapolation）：测试点超出训练分布（更大的数、更长的序列）→ 只有真正学到规律才能做对，证明力强

设计实验时优先测外推能力。

### 一句话总结

没有任何单一测试能"证明"模型学到了规律，但**在严格隔离、同分布、带扰动、甚至超出训练分布的新数据上持续表现正确**，同时 train/val 曲线健康——这组证据就足以在实践中认定模型学到的是规律。反过来，train 好 test 差、对扰动敏感、只认精确样本，就是记忆的典型特征。
